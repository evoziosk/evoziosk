# Evozio

I build Linux desktop tools, developer utilities, and apps that make everyday tasks simpler.

Currently working on the MangoWC port of Caelestia, AI usage monitoring, and a better mobile experience for Bahria students.

[Explore my repositories](https://github.com/evoziosk?tab=repositories)

## Selected work

### [Caelestia · MangoWC](https://github.com/evoziosk/caelestia-shell-mango)

A community port of the Caelestia desktop shell from Hyprland to MangoWC. Adapts workspace management, window previews, panels, and desktop controls to Mango's compositor interfaces.

`QML` `C++` `Quickshell` `Wayland`

### [Guage](https://github.com/evoziosk/guage)

Keep track of AI coding quotas and active agent sessions from a desktop widget or terminal. Includes an MCP server so coding agents can check available limits, too.

`Python` `CLI` `MCP`

### [Bahria CMS](https://github.com/evoziosk/bahria-cms-releases)

A student companion bringing assignments, attendance, grades, and lecture notes into one app, with offline caching and reminders. Available on Android and the web.

`Flutter` `Dart` `Firebase` `Cloudflare`

[Try the web app](https://bahria-cms.pages.dev) · [Android releases](https://github.com/evoziosk/bahria-cms-releases/releases/latest)

## What I work with

QML, C++, Python, and Dart. Linux and Wayland on the desktop; Flutter for mobile; command-line tools for everything in between.
